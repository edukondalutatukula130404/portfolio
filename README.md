# Edukondalu Tatukula - Personal Portfolio

A sleek, modern, typography-first personal portfolio website built with pure semantic HTML5, fluid modern CSS3, and responsive vanilla JavaScript. Designed in exact accordance with high-end designer portfolio references.

## 🚀 Live Preview & Running Locally

Simply double-click `index.html` to open it in any browser (Chrome, Edge, Safari, Firefox), or launch a lightweight local server:

```bash
# Using Node.js
npx serve .

# Or using Python (if installed)
python -m http.server 3000
```
